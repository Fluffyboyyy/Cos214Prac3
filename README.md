## Documentation

Class-level and public-operation documentation is written as Doxygen
comments throughout the source. To generate browsable HTML docs:

```
doxygen Doxyfile
```

This produces `docs/html/index.html`. Open it in a browser to browse the
class list, class diagrams (via Graphviz) and per-member documentation.
