Detailed Description

Concrete Leaf and ConcreteObserver. Provides first aid (the MedicalTeam unit).

Event rule (Task 4.1): unlike every other leaf, FirstAidTent stays active through a WEATHER_ALERT or EVACUATE, since attendees are more likely to need medical help during an incident, not less.
