Detailed Description

Concrete Leaf. Also a ConcreteObserver so it can register with whichever CascadingZone contains it and react to a notice.

Event rule (Task 4.1): a WEATHER_ALERT or EVACUATE pauses the show (outdoor performances cannot safely continue), but a CAPACITY_ALERT is only logged, since the stage itself has no queue to manage.
