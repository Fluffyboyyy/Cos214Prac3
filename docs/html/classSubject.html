Detailed Description

GoF Subject role. Owns the (non-owning, see Observer.h) list of registered Observers and is responsible for notifying them.

Registration policy: attaching an already-registered Observer is a harmless no-op (it will not receive update() twice for one notify() call), and detaching an Observer that is not currently registered is safely ignored.
