Detailed Description

Concrete Leaf and ConcreteObserver. Serves food from a stall.

Event rule (Task 4.1): a WEATHER_ALERT or EVACUATE suspends kitchen service, but a CAPACITY_ALERT is ignored, since a vendor's own queue is managed separately from festival-wide crowd figures.
