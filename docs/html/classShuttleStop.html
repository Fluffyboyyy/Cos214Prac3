Detailed Description

Concrete Leaf and ConcreteObserver. Runs a transport route.

Event rule (Task 4.1): a ShuttleStop never simply closes on WEATHER_ALERT or EVACUATE the way a stage or vendor does. Instead it reroutes, since transport is exactly what attendees need most during an incident.
